# Homepage videos

Drop your Veo 3 generated clips here with these exact filenames:

- `hero-bg.mp4`      — background video behind the hero text (muted, looping, ~10-20s, subtle motion works best since it's dimmed to 25% opacity behind dark overlay)
- `demo.mp4`         — full demo/product-tour video, opens in the modal when "Watch Video" or "See MySchool in Action" is clicked
- `demo-poster.jpg`  — a still frame/thumbnail shown before the demo video plays

Recommended specs:
- MP4, H.264, 1920x1080 or 1280x720
- hero-bg.mp4 under ~8MB (it autoplays on page load, so keep it light)
- demo.mp4 can be larger since it only loads on click

If a file is missing, the hero simply falls back to the plain gradient background — nothing breaks.
